An AI-powered environmental monitoring and multi-hazard early warning IoT command center dashboard featuring interactive ESP32 telemetry simulation, live CartoDB geospatial mapping across 3 monitored hazard zones, synthetic disaster sirens, and a moving multi-layer cyber circuitry motherboard background.

---

## 🚀 Key Features

- **🌐 Dynamic Moving Circuitry Motherboard Background**:
  - Multi-layer fixed cyber background with continuous 3D ambient drift.
  - Sweeping laser scanwave beam illuminating circuit traces.
  - 60 FPS HTML5 Canvas engine simulating flowing electron pulses, pulsing solder nodes, and warm floating bokeh sparks.
  - Auto-overclocks to 2.5x speed during emergency alarm states.

- **📊 Real-Time Multi-Hazard Telemetry Simulation**:
  - **Flood Node (`ESP32-FL-01`)**: Ultrasonic river level monitoring with rate-of-rise derivation.
  - **Fire & Thermal Node (`ESP32-FR-02`)**: BME280 ambient climate + MQ-2 combustible gas and smoke sentry.
  - **Drought & Soil Node (`ESP32-DR-03`)**: Volumetric root-zone soil water deficit and evapotranspiration tracking.
  - Interactive HTML5 range sliders to simulate live incoming ESP32 sensor values.

- **🗺️ Live Geospatial Node Array (CartoDB Dark Matter)**:
  - Interactive Leaflet.js dark map displaying active telemetry stations across India.
  - Divided into **3 Dedicated Interactive Region Parts**:
    - **Region Alpha**: Flood Inundation Basin (`26.20°N, 92.94°E`)
    - **Region Beta**: High-Canopy Forest Ridge (`11.53°N, 76.62°E`)
    - **Region Gamma**: Arid Agro-Zone Basin (`19.88°N, 75.34°E`)
  - "🔭 Fly to Region" camera focus buttons smoothly animating the map to active incident zones.

- **🚨 Integrated Emergency Dispatch & Audio Synthesizer**:
  - Synthesized dual-tone emergency siren generated entirely in code via the browser's **Web Audio API** (no external audio files required).
  - Screen-edge flashing alarm state triggered automatically when sensor values breach >85%.
  - High-Tech Hazard Detected modal with instant contextual dispatch actions for Indian National Emergency Services (112, 100, 101, 108, NDRF 1078).

- **⚡ Standalone Hardware Architecture & Component Showcase**:
  - Alternating Left/Right showcase layout displaying all 8 hardware modules separately:
    1. **ESP32 Microcontroller**: Core processing, dual-core 240 MHz, Wi-Fi & BLE mesh.
    2. **JSN-SR04T Sensor**: Rugged IP67 waterproof ultrasonic transducer.
    3. **BME280 Sensor**: High-precision temperature, humidity, and barometric pressure core.
    4. **MQ-2 Gas & Smoke Sensor**: SnO2 chemical combustion sentry for LPG, CO, and smoke plumes.
    5. **Normal Resistive Soil Moisture Sensor**: Dual-prong immersion gold probe for root-zone moisture.
    6. **NEO-6M GPS Module**: 50-channel GNSS engine with ceramic patch antenna.
    7. **18650 Li-ion Battery & TP4056 Module**: Autonomous solar-harvesting power subsystem.
    8. **Perfboards, Jumper Wires & Resistors**: Double-sided FR-4 matrix and 22 AWG DuPont bus wiring.
  - Each component features custom circular glowing lenses, unique glowing title colors, running glitter sweeps, exact descriptions, project roles, and full technical specifications matrices.

## 🛠️ Technology Stack

- **Frontend Core**: Semantic HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3.
- **Typography**: Clean, accessible Verdana typography (`'Verdana', Geneva, Tahoma, sans-serif`).
- **Mapping**: Leaflet.js with CartoDB Dark Matter tiles.
- **Audio**: Web Audio API (real-time dynamic dual-oscillator siren synthesis).
- **Styling**: Frosted glassmorphism, responsive CSS grid/flexbox, custom glowing neon tokens, running glitter animations.

## 💻 Getting Started Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/PRAVEENB75/ENVIRONMENTAL_HAZARDS-.git
   ```

2. Open the project folder:
   ```bash
   cd ENVIRONMENTAL_HAZARDS-
   ```

3. Launch a local HTTP server:
   ```bash
   # Python 3
   python -m http.server 8085
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:8085/index.html
   ```
